## Scheduled publishing

Laravel checks the article sources every hour and republishes the JSON indexes and sitemap only when they change. Configure the server cron to evaluate the Laravel scheduler every minute:

```bash
* * * * * cd /path/to/blog && php artisan schedule:run >> /dev/null 2>&1
```
